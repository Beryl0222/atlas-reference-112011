# 自然资源图集文稿与图幅

图集编辑部维护章节、地名沿革、图幅和不同渠道的排印信息。
演练资料使用虚构单位、人员与业务文字。资料以 UTF-8 JSON 给出，各文件按收到的顺序保存，正文中引述的名字和词形按原样保留。

## 资料格式

每份资料是记录数组。编号的作用范围是所在资料集，同一业务对象如有不同版本则另列记录。空字符串表示交接文件未填写，空数组表示未列条目。没填写的值无法代替明确的反面事实。

- `data/paragraphs.json` 保存id、版次、位置、正文。位置是该版印前版面的工作标识，位置变动不等于正文变化。

- `data/gazetteer.json` 保存id、名称、生效、止于、范围、沿革。起止年含端点，空止于表示仍沿用，范围为编辑部地理单元代号数组。

- `data/coverage.json` 保存id、版次、图号、页、年、区域。年为图中观测年份，区域来自制图提供的索引，非由题名推断。

- `data/desk.json` 保存id、版次、入口、对象、时间、内容。历史编辑意见和分渠道刊次记录。

- `data/reaches.json` 保存id、支系、上单元、下单元、类型。按编辑部沿河阅读方向登记相邻关系。上游和下游不是行政区界。

- `data/context.json` 保存id、版次、章节、时间口径、编校备注。章节只提供默认口径，题注或明确的引文另行表达年份。

## 阅读与运行

使用 Python 3.11.2 和标准库，无需安装第三方包。在仓库根目录可列出交接资料，或查看一条原始记录的所有版本。测试核查文本能原样读取和资料之间的关联。

```text
python3 -m corpus
python3 -m corpus paragraphs --id P1
python3 -m unittest discover -s tests -v
```
