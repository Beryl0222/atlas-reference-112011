# 自然资源图集文稿与图幅

图集编辑部维护章节、地名沿革、图幅和不同渠道的排印信息。
演练资料使用虚构单位、人员与业务文字。资料以 UTF-8 JSON 给出，各文件按收到的顺序保存，正文中引述的名字和词形按原样保留。

## 资料格式

每份资料是记录数组。编号的作用范围是所在资料集，同一业务对象如有不同版本则另列记录。空字符串表示交接文件未填写，空数组表示未列条目。没填写的值无法代替明确的反面事实。

- `data/paragraphs.json` 保存id、版次、位置、正文。位置是该版印前版面的工作标识，位置变动不等于正文变化。

- `data/gazetteer.json` 保存id、名称、生效、止于、范围、沿革。起止年含端点，空止于表示仍沿用，范围为编辑部地理单元代号数组。

- `data/coverage.json` 保存id、版次、图号、页、年、区域。年为图中观测年份，区域来自制图提供的索引，非由题名推断。

- `data/desk.json` 保存id、版次、入口、对象、时间、内容。历史编辑意见和分渠道刊次记录。

- `data/reaches.json` 保存id、支系、上单元、下单元、类型。按编辑部沿河阅读方向登记相邻关系。上游和下游不是行政区界。

- `data/context.json` 保存id、版次、章节、时间口径、编校备注。章节只提供默认口径，题注或明确的引文另行表达年份。

## 阅读与运行

使用 Python 3.11.2 和标准库，无需安装第三方包。在仓库根目录可列出交接资料，或查看一条原始记录的所有版本。测试核查文本能原样读取和资料之间的关联。

```text
python3 -m corpus
python3 -m corpus paragraphs --id P1
python3 -m unittest discover -s tests -v
```

## 编校链接工具（atlas 包）

`atlas/` 在不改写原始 JSON 的前提下，把正文、题注、表头里的指代解析到地名沿革和图幅覆盖，
并把编辑确认与资料事实分开登记到 `work/ledger.json`。数据目录只含 JSON，隔离运行可用
`python3 -I run_atlas.py ...`（与 `python3 -m atlas ...` 参数相同）。

### 解析规则

- 年代：段落自身年款（含“一九八〇年”）最优先；“旧版图说”按章节备注回到所指年代；
  章节备注的题注年款只约束图面叙述（范围、承接语、题注、图说），“现今/现在”等现状词
  和普通专名叙述取本版最新观测年份，不把历史年款套到今名上。
- 同名异地：“旧渡口”北支 N1、南支 N2 各有记录；同段的支系承接语（如“北支也在这个范围”）
  作为硬约束收窄候选，不靠猜。
- 改名与拆分分开：同名覆盖一致且有统一边界的才算续称；N3 旧双湾 2000 年拆成 N5 西湾、
  N6 东湾；N4“双湾”是无统一边界主体的习惯合称，单独标记。
- 范围：`X 至 Y` 按 `reaches` 沿河相邻关系展开，上游/下游不是行政区界；汇入点登记但
  不沿别的支系继续外推。承接语先回到上文范围，再列支系源段/全支系等多解供复核。
- 旧界：题注声明“采用旧界”时，沿沿革回到旧名所给年代与范围（如西湾回 N3 的 BC），
  不拿现行 N5 的 B 顶替。
- 图幅组：只在同版次、同观测年内选图，返回全部极小覆盖组；必须完整覆盖所指单元
  （允许多覆盖），不允许为省版面只挑一张同名专题图；旧版图号只在旧版反查中命中。

### 命令

```text
python3 -m atlas analyze 春刊 --paragraph P1     # 指代、年代依据、候选原文/年代/覆盖
python3 -m atlas links 春刊                       # 每个解释的图幅组与阻塞分类
python3 -m atlas groups 夏刊 1980 A,B,C           # 直接按年代和单元求极小图幅组
python3 -m atlas decide 春刊 P4 上渡口→双湾西缘 F1 \
    --by 编辑甲 --date 2026-06-02 --channel 纸刊 --basis "确认依据"
python3 -m atlas recheck 春刊                     # 按现行正文/图幅事实复核台账
python3 -m atlas web 春刊                         # 线上稿：未决处保留文字并标图幅待考
python3 -m atlas press 春刊                       # 纸刊闸门：图号/页码/版次未定即不放行
python3 -m atlas reverse 夏刊 --sheet F1          # 从一张图回查该版引用它的段落
python3 -m atlas blocked 夏刊 --kind 印前定位      # 按 地名解释/图幅条件/印前定位 筛选
```

### 确认的有效边界

台账同时保存正文哈希和图幅事实（图号、页、年、覆盖、分图编号）哈希：

- 正文删减限定语（如夏刊 P3 删去“东湾”）→ 正文已变，须重新决定解释；
- 图幅换稿改覆盖或分图编号（如 E4、E7、E8）→ 图幅事实已变，须复核各处引用；
- 仅版面挪行、正文不变 → 解释保留，只提示更新印前定位。

阻塞分三类，`blocked` 可分别查：`地名解释`（同名/拆分/无统一边界主体/年内在效记录缺失）、
`图幅条件`（无完整覆盖图或图签待校）、`印前定位`（移页改号未回填、旧校样未付印）。
线上允许带“图幅待考”发布文字；纸刊 `press` 要求每处链接都有定死图号、页码、版次的确认。
